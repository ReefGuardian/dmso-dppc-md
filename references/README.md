# Reference evidence

These snapshots identify the official files consulted when the notebook was organized on 2026-09-25.

They are not an active force-field installation and the production .mdp snapshot is not approved for execution. It includes an older pressure-control combination requiring review with newer GROMACS.

source_evidence.json records the retrieval URL, byte count, and SHA-256 of each snapshot and the supplied paper files. A SHA-256 identifies file contents; it does not establish scientific validity.

The supplied paper PDFs are not duplicated in this small starter package. SOURCES.md lists their names and DOI links. Provide the relevant paper or supplement to a later Codex session if it needs to inspect the original text or figures.

When preparing an actual run, retain the exact active .itp/.top/.mdp/coordinate files in the project and record their hashes in that run's record. In particular, the full Martini particle-definition file still needs to be obtained for an executable setup.
